# Сервис учёта занятий репетитора (backend)

Backend для сервиса, в котором репетитор ведёт учеников и расписание.

Сначала сервис был спроектирован как проект по системному анализу: https://github.com/kenty-17/tutor-service. Там находятся требования, модель данных, BPMN и описание API. Здесь сервис реализован на Python.

ЧТО УЖЕ РАБОТАЕТ

| Требование | Что сделано |
|---|---|
| FR-2 | Справочник услуг: создать, посмотреть список или одну услугу, переименовать |
| FR-1 | Ученики: создать (можно сразу с новым родителем или привязать к уже существующему), список с фильтром по архиву, карточка с услугой и родителем, редактирование, архивирование ученика |
| FR-3,US-1 | Создание занятия с проверкой пересечения по времени, расписание на период |

Сервис проверяет несколько правил:
1) Занятия не пересекаются по времени, при этом отменённые и перенесённые не считаются;
2) Новый родитель и ученик создаются в одной транзакции, поэтому родитель без ученика в базе не появится;
3) Ученика нельзя удалить, только отправить в архив, и такому ученику нельзя назначить занятие;
4) Время занятия принимается только с часовым поясом.

СТЕК

Python 3.12, FastAPI, Pydantic, PostgreSQL 16, psycopg 3, Docker Compose.

Работа с базой происходит с помощью SQL-запросов через psycopg, значения передаются параметрами.

ИНСТРУКЦИЯ ПО ЗАПУСКУ

Нужны Python 3.12+ и Docker, команды для Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env

docker compose up -d

uvicorn app.main:app --reload
```

При первом запуске docker compose сам создаст таблицы и заполнит их тестовыми данными из папки sql.

Swagger: http://127.0.0.1:8000/docs

ЭНДПОИНТЫ

| Метод | Путь | Что делает |
|---|---|---|
| GET | /health | Проверка работы сервиса и базы |
| POST | /services | Создать услугу |
| GET | /services | Список услуг |
| GET | /services/{service_id} | Одна услуга |
| PATCH | /services/{service_id} | Переименовать услугу |
| POST | /students | Создать ученика |
| GET | /students?is_active= | Список учеников |
| GET | /students/{student_id} | Карточка ученика |
| PATCH | /students/{student_id} | Изменить данные ученика |
| POST | /students/{student_id}/archive | Отправить в архив |
| POST | /lessons | Создать занятие |
| GET | /lessons?from=&to= | Расписание на период |
| GET | /lessons/{lesson_id} | Одно занятие |

СТРУКТУРА

```
app/
  main.py         Приложение и подключение роутеров
  config.py       Настройки из .env
  database.py     Подключение к базе
  schemas.py      Схемы запросов и ответов
  routers/        Эндпоинты услуг, учеников и занятий
sql/              Таблицы и тестовые данные из аналитического проекта
```
